# Control LED Button

## Deskripsi

Project Arduino Uno untuk mengontrol
tiga LED menggunakan tiga push button.

## Hardware

- Arduino Uno
- 3 LED (Merah, Hijau, Kuning)
- 3 Push Button
- Resistor
- Breadboard
- Jumper Wire

## Pin Configuration

- LED Merah: D7
- LED Hijau: D6
- LED Kuning: D5
- Button Merah: D10
- Button Hijau: D9
- Button Kuning: D3

## Cara Kerja

Ketika tombol merah ditekan, LED merah menyala, lampu kuning dan hijau mati.
Ketika tombol kuning ditekan, LED kuning menyala, lampu merah dan hijau mati.
Ketika tombol hijau ditekan, LED hijau menyala, lampu merah dan kuning mati.
Ketika semua tombol dilepas, semua LED mati.
