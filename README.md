# Control LED Button

## Deskripsi

Project Arduino Uno untuk mengontrol
satu LED menggunakan satu push button.

## Hardware

- Arduino Uno
- 1 LED (Merah)
- 1 Push Button
- Resistor
- Breadboard
- Jumper Wire

## Pin Configuration

- LED Merah: D7
- Button Merah: D10

## Cara Kerja

Ketika tombol ditekan, LED merah menyala.
Ketika tombol dilepas, LED merah mati.
